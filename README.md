# Raghul Vel Pandian PJ — Portfolio

Static responsive portfolio built with HTML, CSS and JavaScript.

## Deploy on Vercel
1. Upload all files in this folder to a public GitHub repository.
2. Import the repository in Vercel.
3. Deploy with no build command required.
